#### 🚀 Features
- **Quantum-Safe Addresses:** `pqc_` format, secured by ML-DSA87 (Dilithium)
- **Trust Wallet UI:** Real mobile-first design with Assets, Send, Receive
- **PQC Wrapped Tokens:** Bitcoin, Ethereum secured with quantum signatures
- **Secure Enclave Simulation:** Private key never leaves device
- **100% Client-Side:** No backend, no data collection

#### 🧬 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JS
- **Cryptography:** ML-DSA-87 (NIST FIPS 204), ML-KEM-768 (NIST FIPS 203)
- **Hosting:** GitHub Pages PWA

#### 🔐 Why Quantum-Safe?
Current wallets (ECDSA/secp256k1) will be broken by Shor's algorithm. QTrust uses lattice-based cryptography approved by NIST in 2024.

| Feature | Traditional Wallet | QTrust Wallet |
| :--- | :--- | :--- |
| Signature | ECDSA (Breakable) | ML-DSA87 (Quantum-Safe) |
| Key Exchange | ECDH | ML-KEM-768 |
| Security | ~128-bit classical | 256-bit quantum |
